# Портфолио — Иван Чучков

Одностраничный сайт-портфолио: продакт-менеджер проектов.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `portfolio`.
2. Загрузите в него содержимое этой папки: `index.html`, `app.js`, папку `media`.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/portfolio/`.

## Структура

- `index.html` — разметка и стили
- `app.js` — колода карточек, вкладки, свайп, автозапуск видео
- `media/` — фотографии, логотипы и видео геймплея
